# ChatGPT へのアバターパーツ依頼書 — 人柴村（全 78 枚）

**追手門学院大学 理工学部「コンピュータインタラクション」授業ワーク**

アバター工房（`avatar.html`）には、SVG で描いた標準パーツが最初から入っています。人間に加えて、柴犬・猫・うさぎ・きつね・お化け・精霊・ロボットも選べます。**画像パーツが 1 枚も無くても動きます。**
ここで作る画像パーツは、標準パーツに「選べるパーツ」として追加されます。少しずつ増やせば大丈夫です。

画像パーツは 1 枚ずつ別々に作るので、**位置と大きさがそろうかどうか**がいちばん大事です。
そのために次の 2 つを用意しています。

- `docs/avatar_template.png` … 灰色の「素体」（顔と肩だけのマネキン）。ChatGPT に添付して「これにぴったり重なるように」と頼みます。
- `tools/avatar_parts.py` … 受け取った画像の描かれている範囲を自動で見つけ、決まった位置・大きさにそろえます。多少ずれていても直ります。

`docs/avatar_guide.png` は、各パーツがどこに来るかを示した目安図です（自分の確認用。ChatGPT に添付しても構いません）。

## 作業の流れ

1. ChatGPT で新しいチャットを開き、**`docs/avatar_template.png` を添付して**、下の「① 最初に送る共通指示」を送ります。
2. 試しに出てきた 1 枚（`hair_01`）を見て、画風や位置を確認します。気に入らなければ調整してもらい、決まったら「この画風と位置で統一してください」と伝えます。
3. **同じチャットのまま**、② 以降の依頼文を **1 枚ずつ** 送ります。毎回「素体に重ねる位置で、透明背景で」と念押しすると安定します。
4. 画像をダウンロードし、**表のファイル名に変えて** `avatar_raw/` フォルダに入れます（拡張子は .png のままで構いません）。
5. 変換します。
   ```bash
   pip install pillow
   python tools/avatar_parts.py
   ```
   `assets/avatar/` に 512×512 の WebP と、パーツ一覧（`manifest.json`）ができます。
6. `avatar_raw/_preview.png`（全パーツを素体に重ねた一覧）を開いて、位置のずれを確認します。
   - ずれていたら `avatar_raw/adjust.json` に書いて、5 をやり直します。
   ```json
   {
     "hair_06": {"scale": 1.1, "dx": 30, "dy": 0},
     "head_01": {"scale": 0.9, "dy": -20}
   }
   ```
   - 数字は 1024×1024 の画像を基準にしたピクセル数です。`dx` はプラスで右へ、`dy` はプラスで下へ動きます。
   - ChatGPT の位置がもともと正確なら、`{"mode": "keep"}` で自動の位置合わせを止められます。
7. `assets/avatar/` を GitHub に push すると、アバター工房に「画像」と書かれたパーツが増えます。`avatar_raw/` は push されません。

> 背景が透明にならなかった画像も、四隅から背景色を自動で取り除きます。ただし、パーツの色が背景と近いと一緒に消えることがあるので、透明背景で出してもらうのが確実です。

## ① 最初に送る共通指示（素体画像を添付してから、コピーしてそのまま送る）

```
添付したのは、アバター作成アプリの「素体」です（1024×1024、灰色のマネキンの顔と肩）。
これから、この素体に重ねて使う「着せ替えパーツ」を、全部で78枚、1枚ずつ作ってもらいます。
すべて次の共通ルールを守ってください。

【用途】
大学の授業で使うウェブゲーム「人柴村（じんしばむら）」で、学生が自分のアバターを組み立てるためのパーツです。
舞台は、ものづくりと科学が好きな人たちのほのぼのした村「RIKOU村」。人間のほかに、柴犬・猫・うさぎ・きつね・お化け・精霊・ロボットも暮らしています。
髪・目・口・服・人外の頭などを別々の画像として重ねて表示します。

【画風】
フラットなイラスト。濃いこげ茶色（#2A1D16）の、太さが均一なはっきりした輪郭線。全体にほのぼのした、明るく温かい色づかい。
ベタ塗りに、影は1段だけ。やわらかいデフォルメで、親しみやすいアプリのアイコンのような絵柄。
等身はふつう（大きすぎる目や、ちびキャラにはしない）。正面向きで、左右対称を基本にする。

【必ず守ること】
・出力は正方形 1024×1024、背景は完全に透明（透過PNG）。
・頼んだパーツだけを描く。素体（灰色のマネキン）や、他のパーツは描かない。
・素体に重ねたときにぴったり合う位置と大きさで描く（顔の中心は画像の左右中央）。
・文字、ロゴ、署名、透かし、枠線は入れない。
・季節やイベントを感じさせるもの（桜、雪、紅葉、ハロウィン、クリスマス、正月など）は入れない。どの季節でも使える汎用的なデザインにする。
・こわい表現は入れない（お化けや精霊も、かわいく親しみやすく）。
・実在の人物や、既存の作品のキャラクター、特定の作家やスタジオの画風に似せない。
・暴力的・性的な要素は入れない。

了解したら、まず試しに次の1枚だけ作ってください。

ファイル名：hair_01（髪）
短めのショートヘア、こげ茶色。素体の頭にかぶせる位置で、頭頂部と前髪、耳の上まで。
顔の部分（おでこから下）は透明のままにして、髪だけを描く。
```

## うまくいかないときのコツ

- **背景が透明にならない** → 「背景を完全に透明にした PNG で出し直してください」と頼みます。白い背景のままでも、変換ツールがある程度は取り除きます。
- **素体まで描いてしまう** → 「灰色のマネキンは描かず、○○だけを描いてください」と伝えます。
- **画風がぶれる** → 「hair_01 と同じ線の太さ・塗り方で」と書き添えます。
- **左右非対称なパーツ**（ポニーテール、片側の髪飾り、ウインクなど）は、自動の位置合わせで少しずれやすいです。`_preview.png` で確認して、`adjust.json` で直してください。
- **パーツを増やしたい** → 同じ形式で `hair_13` のように番号を続けて作れば、自動で追加されます。名前は `hair_braid` のような英数字でも構いません。
