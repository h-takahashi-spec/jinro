# ChatGPT への画像依頼書 — 人柴村（全 47 枚）

**追手門学院大学 理工学部「コンピュータインタラクション」授業ワーク**

画面（`index.html`）は、`assets/` フォルダに置いた画像を自動で読み込みます。
**画像が全部そろっていなくても動きます。** 無いものは CSS や絵文字の代わりの表示になるので、優先度の高いものから少しずつ作ってください。

> アバターのパーツ（髪・目・服・人外の頭など）は、別の依頼書 [`avatar_parts_prompts.md`](avatar_parts_prompts.md) にまとめています。

## 作業の流れ

1. ChatGPT で新しいチャットを開き、**「① 最初に送る共通指示」** を送ります。
2. 試しに出てきた 1 枚（マスコットの `mascot`）で、画風とキャラクターを確認します。決まったら「この画風とキャラクターで統一してください」と伝えます。
3. **同じチャットのまま**、② 以降の依頼文を **1 枚ずつ** 送ります。
4. 画像をダウンロードし、**表のファイル名に変えて** `assets_raw/` に入れます。
5. 変換します（1 枚 2〜3MB → 100〜300KB 程度の WebP になります）。
   ```bash
   pip install pillow
   python tools/optimize_images.py
   ```
6. `assets/` を GitHub に push すれば反映されます。

> 透明背景が必要な画像（マスコット・紋章・スタンプ）は、透明のまま変換されます。背景が付いてしまったときは、変換時に注意が表示されます。

## ① 最初に送る共通指示（コピーしてそのまま送る）

```
これから、大学の授業で使うウェブゲーム「人柴村（じんしばむら）」の画像を、全部で47枚、同じ世界観でお願いします。
1回に1枚ずつ頼むので、すべて次の共通ルールを守ってください。

【ゲームの内容】
人狼ゲームをもとにした、ほのぼのした推理ゲームです。
村に人に化けた柴犬がまぎれこんでいて、村人たちが話し合いで見つけ出します。
夜になると柴犬は、村人をひとり「もふもふの国」へ連れていきます（こわい表現ではなく、いたずらっぽく、かわいく）。

【舞台：RIKOU村（りこうむら）】
小高い丘の上にある、ものづくりと科学が大好きな人たちの小さな村。
石畳の広場、井戸、時計塔、風車、歯車の看板がかかった工房、小さな天文台、ソーラーパネルの付いた屋根、ロボットの形の郵便ポストなど。
人間のほかに、柴犬・猫・うさぎ・きつね・お化け・精霊・ロボットも、なかよく暮らしています。
木々は一年中の緑。どの季節ともいえない、おだやかな気候です。

【画風】
・背景・場面・カードの絵：やわらかい水彩タッチの絵本のイラスト。細めの茶色の輪郭線、パステル調で明るく温かい色。光はやさしく、影は淡い。
・キャラクター・アイコン（マスコット、スタンプ、紋章、村人の顔）：フラットなイラスト。濃いこげ茶色（#2A1D16）の太さが均一な輪郭線、ベタ塗りに影1段。丸みのあるかわいいデフォルメ。
・全体の色：クリーム色、はちみつ色（#F0A23B）、若草色、空色を中心に。夜は深い藍色とラベンダー色で、こわくならないように。

【必ず守ること】
・文字、数字、ロゴ、署名、透かしは入れない（ゲームの文字はアプリ側で重ねます）。
・季節やイベントを感じさせるもの（桜、紅葉、雪、ハロウィン、クリスマス、正月など）は描かない。
・こわい・痛い・悲しすぎる表現（血、けが、武器で傷つける場面、泣き叫ぶ顔）はしない。
・実在の人物、既存の作品のキャラクター、特定の作家やスタジオの画風に似せない。
・「透明背景」と書いた画像は、背景を完全に透明にした PNG で出す。

了解したら、まず試しに次の1枚だけ作ってください。

ファイル名：mascot（正方形・透明背景）
村の案内役の犬「ポチ」。雑種の犬（柴犬ではない）。クリーム色と茶色のぶち模様、片耳だけ垂れていて、しっぽはくるんと巻かずにふさふさ。首にはちみつ色のスカーフ、首から小さな学生証（文字は入れない、四角いカードだけ）をさげている。柴犬とはっきり見分けがつく姿にする。
二本足で立って、片手を元気にふって「ようこそ！」とあいさつしているポーズ。全身。にっこり笑顔。
キャラクター・アイコンの画風で。
```
