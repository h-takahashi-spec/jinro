**追手門学院大学 理工学部「コンピュータインタラクション」授業ワーク**

## なぜ描き直すのか

| ファイル名 | 今の画像の問題 |
|---|---|
| `head_06`（王冠） | 斜め上から見た絵なので、王冠の**内側（奥の壁の裏側）と穴**が見えている。頭にかぶせると、頭の上に穴の開いた輪が浮いて見える |
| `head_04`（バンダナ） | 結び目と布の端が顔の右横（目の高さ）に垂れているので、**頭の上に深くかぶせると結び目が右目にかかる**。目にかからない位置だと浅すぎて浮いて見える |
| `head_08`（ヘアバンド） | 輪っか全体が描かれているので、**頭の後ろ側を通る輪**まで見えている。頭にかぶせると、天使の輪のように頭の上に浮いて見える |

アバターは「頭の画像の上に帽子の画像を重ねる」作りです。帽子の後ろ側を頭の裏に隠すことはできません。
そこで、**頭にかぶせたときに見えるはずの、前側だけ**を描いてもらいます。

## 作業の流れ

1. 前に着せ替えパーツを作ってもらったチャットが残っていれば、**同じチャット**で下の依頼文を送ります。画風がそろいます。
   - チャットが残っていない場合は、新しいチャットで `docs/avatar_template.png`（素体）と、今の `avatar_raw/head_06.png`・`avatar_raw/head_08.png` を添付して、`docs/avatar_parts_prompts.md` の「① 最初に送る共通指示」を送ってから、下の依頼文を送ります。
2. 出てきた画像を `head_04.png`・`head_06.png`・`head_08.png` という名前で `avatar_raw/` に入れて、今の画像と置きかえます。
3. 変換します。
   ```bash
   python tools/avatar_parts.py
   ```
4. `avatar_raw/_preview.png` で位置を確認します。今の画像に合わせた位置の調整（`avatar_raw/adjust.json` の `head_04`・`head_06`・`head_08`）が残っているので、新しい画像で位置がずれていたら、その行を消すか数字を変えてください（Claude に画像を渡してもらえれば調整します）。

## 依頼文 1：王冠（head_06）

```
ファイル名：head_06（帽子・髪飾り）の描き直し
小さな金色の王冠。前に作ってもらった王冠と同じデザイン・色・大きさで、見る角度だけを変えてください。

【描き直してほしい理由】
今の王冠は少し上から見た角度なので、王冠の内側（奥の壁の裏側）と、上の穴が見えています。
頭にかぶせて使うと、頭のてっぺんに穴の開いた輪が浮いているように見えてしまいます。

【描き方】
・真正面から、目の高さで見た王冠にする。上から見下ろさない。
・王冠の内側・奥の壁の裏側・上の穴は、まったく見えないようにする。見えるのは王冠の「前側の外側」だけ。
・王冠の下のふちは、ゆるやかに下へふくらむ弧にする（頭の丸みに沿って、おでこの上に乗っている感じ）。下のふちが楕円の輪にならないようにする。
・とがった部分（3〜5本）は、前側に並んでいるものだけを描く。奥にあるはずのとがりは描かない。
・素体の頭のてっぺん（髪の上）に乗る位置と大きさ。幅は頭の幅の6割くらい。
・頭や髪は描かない。王冠だけ。背景は完全に透明（透過PNG）、1024×1024。
```

## 依頼文 2：ヘアバンド（head_08）

```
ファイル名：head_08（帽子・髪飾り）の描き直し
細い革のヘアバンド。前に作ってもらったヘアバンドと同じ色・太さ・留め具で、形だけを変えてください。

【描き直してほしい理由】
今のヘアバンドは輪っか全体が描かれているので、頭の後ろ側を通る部分まで見えています。
頭にかぶせて使うと、天使の輪のように頭の上に浮いて見えてしまいます。

【描き方】
・頭にかぶせたときに見える「前側だけ」を描く。頭の後ろを通る部分は、頭に隠れて見えないので描かない。
・形は、おでこの上（髪の生えぎわより少し上）を、左のこめかみから右のこめかみまで横切る、ゆるやかに上へふくらむ弧。輪（楕円）にはしない。
・弧の左右の端は、頭の横（耳の少し上）で、髪の中に入っていくように自然に終わらせる。切り口がスパッと見えないよう、端は少し細くするか、髪に隠れる前提で丸くおさめる。
・留め具（小さな金具）は前側の中央より少し横に1つ。
・幅は素体の頭の幅とほぼ同じ（頭からはみ出さない）。素体の頭に重ねたとき、おでこの上に巻いている位置に描く。
・頭や髪は描かない。ヘアバンドだけ。背景は完全に透明（透過PNG）、1024×1024。
```

## 依頼文 3：バンダナ（head_04）

```
ファイル名：head_04（帽子・髪飾り）の描き直し
頭に巻いた布のバンダナ。前に作ってもらったバンダナと同じ布（紺色に白い小さな模様）で、かぶり方と結び目の位置を変えてください。

【描き直してほしい理由】
今のバンダナは、結び目と布の端が顔の右横（目の高さ）に垂れています。
頭に深くかぶせると結び目が右目にかかり、浅くすると頭から浮いて見えてしまいます。

【描き方】
・頭のてっぺんから、おでこの上（眉より上）まで、頭をすっぽり包むように深くかぶっている形にする。
・結び目は頭のうしろ側にあって、正面からは見えない。もしくは、頭の上の左右どちらかの角に小さく出ている程度にする。
・布の端（結んだあとの余り）は、顔の横や目の高さに垂れ下がらないようにする。見せる場合は、頭の上の後ろ側に小さくちょこんと出る程度。
・下のふちは、おでこの上を左右のこめかみまで横切る、ゆるやかなカーブ。ふちより下（目・顔）には布を描かない。
・素体の頭に重ねたとき、頭の形に沿ってぴったりかぶっている位置と大きさ。頭からふくらみすぎない。
・頭や髪は描かない。バンダナだけ。背景は完全に透明（透過PNG）、1024×1024。
```

---

> どれも、うまくいかないときは「真正面・目の高さから見て」「内側が見えないように」「前側だけ」をもう一度伝えると直りやすくなります。
